설정 이전 원칙

  • 분리 계정: 숫자는 Hover로. 기존 None/Ratio/Percent 저장값은 삭제하지 않고 단일 한도 계정의 선택으로 보존합니다.
  • 알림: 기존 master·80/90 사용자 지정값·앱 상태 알림 설정을 유지합니다. 같은 기준을 두 계열에 각각 적용하고, 안팎 배치는 알림 의미를 바꾸지 않습니다.
  • 급증: Quiet/Normal/Bold 선택은 유지합니다. 두 이모지 세트도 계속 선택할 수 있습니다. 기존 $0.05/$0.30 증가 기준을 유지하고, 유효한 서버 사용률의 +5/+15%p 기준과 함께 평가합니다. 금액 수집 지연 자체는 새 소비로 알리지 않습니다.
  • 기존 단일 한도/퍼센트 전용 계정: 기존 표시·Ratio 사용 가능 여부·on-demand 동작을 유지합니다. 적용되지 않는 모델군 설정은 비활성화합니다.
